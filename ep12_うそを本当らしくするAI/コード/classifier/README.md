# 自前の判定器（単語数え）

学習：2026-10-17、Claude の砂場で `train_bow.py`。原典 Zenodo の `hippocorpus.csv` の split=train（4,542文。想起＝本当、想像＝うそ）。
作り：TF-IDF（1〜2語、min_df=3、sublinear）＋ロジスティック回帰。語彙 61,204。`bow.py` が weights.json を読んで純Pythonで同じ計算をする（sklearn との差 1e-15）。

## 性能（原典と同じテスト505文）
| | 自前（全文） | 自前（短縮文） | 原典 ModernBERT |
|---|---|---|---|
| 正答率 | 0.723 | 0.719 | 0.78 |
| AUC | 0.794 | 0.777 | 0.86 |

- 攻撃対象262文（原典が確信度0.8以上で正しく当てた文）：自前は234/262（89.3%）を正解、AUC 0.955
- テスト505文で ModernBERT と同じラベル：77.4%

## 著者の書き換え文（ModernBERT向けに作られたもの）を自前の判定器に通した結果
判定器が元の文を正しく当てていた系列だけ。「初回」＝1回目の書き換え。
| 攻撃者・元のラベル | 系列 | 初回で反転 | 初回のΔ本当確率 |
|---|---|---|---|
| 人間・うそ→本当 | 125 | 13.6% | +5.4 |
| 人間・本当→うそ | 70 | 31.4% | −6.4 |
| Llama 3.3・うそ→本当 | 156 | 32.7% | +11.1 |
| Llama 3.3・本当→うそ | 90 | 8.9% | −2.2 |
→ 攻撃者が見ていない判定器でも、非対称の向きは同じ（Llamaはうそ→本当が得意、人間は本当→うそが得意）。
