各フォルダの `はじめに.txt` に、実験の内容・ファイルの説明・主な結果・弱点・出典があります。

## ファイルの形
- `結果.csv`・`質問一覧.csv`：Excel でも開けます
- `生データ_log.jsonl`：1行が1回の回答（AIの回答の全文入り）
- `コード/`：質問の作成・検算・送信・回収・集計に使ったプログラム（Python）
